# Portfolio Notice

FraudShield-Showcase adalah ringkasan portofolio, bukan distribusi aplikasi
produksi.

Repository ini sengaja hanya menampilkan konteks masalah, arsitektur
konseptual, metrik evaluasi, materi demo, dan batasan responsible use. Detail
yang dapat mempermudah reproduksi atau deployment langsung—termasuk source
code, dataset kerja, serialized model, notebook, training configuration,
feature contract, payload API, dan implementation internals—tidak disertakan.

Semua hasil model pada repository ini berasal dari data sintetis. Setiap
penggunaan di dunia nyata memerlukan validasi independen, governance, security
review, monitoring, dan keputusan manusia.
